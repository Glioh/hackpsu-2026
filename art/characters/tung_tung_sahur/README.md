# Tung Tung Sahur

Stylized wooden log fighter with carved grain, end-grain rings, wide eyes,
bare feet, and a compact bat. Uses the existing fighter scale, joint names,
head wobble tag, and standard shoulder-to-wrist length.

Rebuild the playable GLB from the repository root:

```sh
node art/characters/tung_tung_sahur/build_tung_tung_sahur.mjs
```

The generator uses the project's Three.js dependency and needs no Blender install.
Output: `host/assets/characters/tung_tung_sahur.glb`. Select **Tung Tung Sahur**
in either team's fighter picker.
